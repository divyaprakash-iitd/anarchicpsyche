# Anarchicpsyche logo suite

A vector redraw of the original blog logo (`original/ap_logo.png`, from the
WordPress site, October 2020), plus everything derived from it. All files are
generated by `tools/brand/build.js` from one set of measured coordinates, so edit
the script and rebuild rather than editing the files by hand.

```
node tools/brand/build.js      # needs Playwright + Chromium
```

## The mark

A sun (circle with three hatch strokes) setting behind the horizon, with a peak
whose apex is the sun's centre. The redraw sits on the original 489 x 452 grid,
with positions and stroke widths measured from the original image.

| Weight | Stroke | Use it for | Detail |
|---|---|---|---|
| `fine` | 6.6 | 200 px and larger: prints, the big lockup | the original drawing |
| `regular` | 16 | 40 to 200 px: site header, homepage, lockups | all lines |
| `bold` | 26 | app icons (64 to 512 px) | inner legs and top hatch dropped |
| `tiny` | 44 | favicons (16 to 32 px) | sun ring, horizon and peak only |

Thin lines disappear at small sizes, so pick the weight by the size it will be shown at.

## Colours

| Name | Hex | |
|---|---|---|
| Ink | `#111111` | mark on light backgrounds |
| Paper | `#f6f1e7` | mark on dark backgrounds, icon tiles |
| Slate | `#1e293b` | dark tile (the site's dark-mode background) |
| Sun | `#e08a2c` | optional accent, `mark-sunrise*` only |

## Files

`svg/` holds the vectors (use these wherever possible). `png/` holds transparent renders for apps that
need bitmaps.

- `mark-{fine,regular,bold,tiny}-{black,white}`: the mark alone
- `mark-sunrise`, `mark-sunrise-regular`: amber sun, ink peak
- `lockup-{black,white}`: mark + wordmark side by side, the wordmark on the horizon line
- `lockup-fine-{black,white}`: the same with the fine mark (large sizes)
- `lockup-stacked-{black,white}`: mark above the wordmark
- `app-icon-{light,dark}`: square tiles (1024 px), safe for Android's round mask
- `favicon.svg`: transparent, switches ink/paper with the browser theme
- `social.svg`: 1200 x 630 share card

Wordmark: "anarchicpsyche" in Jost (SIL Open Font License), converted to outlines
by `tools/brand/wordmark.py`, so no font needs to be installed.

## On the website

- Header: `assets/img/logo.svg` (regular, `currentColor`, so it follows light/dark mode)
- Homepage heading: `assets/img/logo-stacked.svg` (same)
- Favicons and app icons: `static/` (`favicon.svg`, `favicon.ico`, PNGs, `site.webmanifest`)
- Share image for pages without a cover photo: `assets/img/social.png`

Spacing: keep clear space of at least half the sun's diameter around the mark, and
don't stretch, rotate, outline or recolour it beyond the colours above.
